# pvsz 架构说明

> 配套图纸：[`pvsz_架构.drawio`](pvsz_架构.drawio)（4 页，用 draw.io / diagrams.net 打开）
> 行号基于 2026-09-15（分支 `perf/smoothness-audit`，提交 `7bbd851`）。

## 全局一句话

27 个 Python 模块、约 1.3 万行。`main.py` 拥有进程生命周期（显示、时钟、事件泵），
`game.py` 里的 `Game` 类拥有世界（一块 1400×600 的草坪和 9 个状态），每 16.67ms
推演一次：读输入 → 更新 21 个步骤 → 画一帧。没有线程，没有异步，全部单线程同步。

## 模块分层（图纸第 1 页）

依赖方向严格自上而下，**零循环依赖**（个别跨层引用用函数内延迟导入打破，图上标了「防环」虚线）：

| 层 | 模块 | 职责 |
|---|---|---|
| L0 入口 | `main.py` | SDL 初始化、主循环（睡眠 + 末 2ms 忙等的混合 pacing）、dt 钳到 0.05s、长停顿(>200ms)后重同步时钟 |
| L1 世界 | `game.py` | `Game` 状态机 + 每帧 21 步更新管线（update 在 `:1558`，draw 在 `:1928`） |
| L2 系统 | `entities.py`（植物/僵尸/投射物/阳光）、`wave.py`（波次编排）、`ai.py`（波次导演 + 战场情报）、`grid.py`、`ui.py` | 各自领域，只向下依赖 |
| L3 表现 | `fx.py`、`particles.py`、`fade_cache.py`、`assets_loader.py`、`audio.py` | 一切「看起来漂亮」的东西；所有缓存都在这层，且全部有界 |
| L4 数据 | `levels.py`、`save.py`、`i18n.py` | 关卡表、原子写存档（tmp+fsync+os.replace，损坏自动隔离 `.corrupt`）、中英文 |
| L5 地基 | `constants.py` | 纯数据常量，被全体引用，不引用任何人 |

## 一帧的流水线（图纸第 2 页）

```
pacing(睡眠到点) → 算 dt(≤0.05) → pygame 事件泵 → Game.handle_event
  → Game.update(dt)  ── 21 步 ──
  → Game.draw() → flip
```

QUIT / VIDEORESIZE / 焦点丢失（自动暂停）三条支路在事件步分叉。实测：稳态 p95 1.5ms，
253 僵尸饱和 p95 9.2ms，120 弹幕饱和 p95 8.5ms——预算 16.67ms，均有余量。

## 状态机（图纸第 3 页）

9 个状态：MENU / LEVEL_SELECT / PLAYING / PAUSED / LEVEL_COMPLETE / GAME_OVER /
SURVIVAL_COMPLETE(死状态，永不进入) / HELP / LANG。每条迁移边在图纸上标了源码行号。

## 一帧数据流与循环（图纸第 4 页）

四个闭环，这就是「游戏怎么工作」的全部答案：

1. **经济环**：天空掉阳光 + 向日葵产阳光 → 点击/自动收集入罐 → 种子栏扣费种植/升级。
2. **战斗环**：植物开火 → `projectiles` 池 → 横扫矩形碰撞（`:1695` 附近，地下矿工直接
   跳过、豌豆从头顶飞过）→ `Zombie.take_damage` → 死亡回收进 `dead_zombies` → 奖励/粒子。
3. **波次环**：`wave.py` 按编排表出怪 → `create_zombie`（`:2794`，波次速度/咬伤倍率在
   出生时一次性施加并记录 `_speed_mult`）→ `ai.BattlefieldIntel` 每帧快照 → 导演
   （Director）据此决定下一波成分。
4. **回收环**：所有实体池（僵尸/子弹/阳光/浮字/粒子）每帧原地压缩存活者，不重建列表，
   无 GC 抖动。

僵尸是**单类 13 型**：撑杆、气球、矿工、蹦极、报纸、战术、医生、指挥官、boss……全部靠
`Zombie` 上的标志位分支实现（`entities.py:1753` 起），新增类型不新增类。

## 性能与稳定性的设计约定

- **缓存 everywhere，且全部有界**：淡出 surface 按 (图, 1/32 alpha 档) 记忆化；精灵旋转
  24 档预烘焙；爆炸环 4px、火球 16px 阶梯量化；文字/粒子旋转分桶；`fx._text_cache`
  上限 2048（溢出丢最旧一半，miss 自愈）。
- **禁止在共享缓存 surface 上 set_alpha/fill**——只 blit；需要淡出就取副本（fade_cache 保证副本也有缓存）。
- **半透明色不能直接画到 screen**（canvas 无逐像素 alpha，会画成实心黑块），一律走 `fx.alpha_rect`。
- **测试一律 `SDL_VIDEODRIVER=dummy` + 存档重定向到 `$TMPDIR`**，绝不碰随包发布的 `save.json`。
